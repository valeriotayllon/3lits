# SAAS - Sistema de Agendamento Online

Sistema completo de agendamento online responsivo (Mobile-First), com suporte a banco de dados em nuvem via **Supabase** (sem precisar de back-end próprio) e fallback automático para armazenamento local (`localStorage`).

Todos os arquivos estão consolidados na **mesma pasta** (sem subpastas), facilitando o versionamento e publicação direta no GitHub Pages.

---

## 📁 Estrutura de Arquivos

| Arquivo | Descrição |
| :--- | :--- |
| `index.html` | Tela de agendamento do cliente (serviços, atendente, data/horário e cadastro). |
| `admin.html` | Painel de controle do profissional com métricas do dia, lista de agendamentos e cancelamentos. |
| `servicos.html` | Cadastro e gerenciamento do catálogo de serviços (preços e durações). |
| `login.html` | Tela de autenticação para acesso restrito à área de administração. |
| `style.css` | Folha de estilo global responsiva, limpa e moderna. |
| `supabase-config.js` | Arquivo central de configuração da URL e Chave do Supabase. |
| `app.js` | Lógica de agendamento, validação de horários e gravação em banco/local. |
| `admin.js` | Lógica do painel de controle, cálculo de faturamento e status da agenda. |

## ⚡ Como Conectar ao Supabase (Passo a Passo)

1. Crie seu projeto em [supabase.com](https://supabase.com).
2. No menu **SQL Editor**, copie e execute o script abaixo:

```sql
-- Criação da tabela de usuários
create table if not exists usuarios (
  id bigint generated by default as identity primary key,
  nome text not null,
  telefone text not null,
  email text,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- Criação da tabela de agendamentos
create table if not exists agendamentos (
  id text primary key,
  servico text not null,
  preco numeric not null,
  profissional text not null,
  data text not null,
  horario text not null,
  cliente_nome text not null,
  cliente_telefone text not null,
  observacoes text,
  status text default 'confirmado',
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- Desabilita RLS para testes iniciais sem login de autenticação avançado
alter table usuarios disable row level security;
alter table agendamentos disable row level security;
```

3. Abra o arquivo `supabase-config.js` e preencha com a sua **Project URL** e sua **anon key** obtidas nas configurações do Supabase (**Project Settings > API**):

```javascript
const SUPABASE_URL = "https://SEU-PROJETO.supabase.co";
const SUPABASE_ANON_KEY = "SUA-CHAVE-ANONIMA-LONGA";
```

*Nota: Se você não configurar o Supabase imediatamente, o sistema continua funcionando perfeitamente gravando os dados no navegador (`localStorage`).*

## 🚀 Como subir para o GitHub e colocar no ar (GitHub Pages)

1. Crie um novo repositório no seu GitHub (exemplo: `saas-agendamento`).
2. Faça o upload de todos os arquivos descompactados diretamente na raiz do repositório.
3. No repositório, clique em **Settings > Pages**.
4. Em **Branch**, selecione `main` e pasta `/(root)`.
5. Clique em **Save**. Em instantes seu sistema estará no ar gratuitamente no link `https://seu-usuario.github.io/saas-agendamento/`.
